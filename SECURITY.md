# Security policy

Report vulnerabilities privately to [alsocwa@proton.me](mailto:alsocwa@proton.me). Include the affected version, impact, and steps to reproduce the issue.

SurfaceMap is a single-user application with a web port bound to `127.0.0.1`. Keep the interface private and run it on a trusted machine. Use the project scope controls to authorize targets for scanner jobs.

Scan artifacts and project exports can contain sensitive infrastructure details. Remove credentials, private targets and identifying data from any material you share with a report.
