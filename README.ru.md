# SurfaceMap

**Локальная платформа для аудита и картирования поверхности атаки.**

[English](README.md) · **Русский**

[Установка](#setup) · [Первый аудит](#audit) · [Команды](#commands) · [Решение проблем](#troubleshooting) · [Удаление](#uninstall) · [Лицензия](#licensing) · [Донаты](#donate)

SurfaceMap собирает результаты сканеров в одном проекте. Проследите связи между доменами, IP-адресами, сервисами, веб-маршрутами и находками. Запустите готовый аудит, настройте отдельный сканер или импортируйте результаты уже проведённой проверки.

| Задача | Что доступно |
| --- | --- |
| **Обнаружение** | Домены, DNS-записи, открытые сервисы, веб-технологии и маршруты |
| **Разбор** | Интерактивная карта, журналы сканеров и доказательства по находкам |
| **Сравнение** | Изменения между аудитами, экспорт карты и отчётов |

<a id="setup"></a>

## Быстрый старт

Клонируйте репозиторий и перейдите в папку проекта.

```bash
git clone https://github.com/morreti-pntst/SurfaceMap.git
cd SurfaceMap
```

**Kali, Debian, Ubuntu**

```bash
bash ./install.sh
```

Запускайте установщик от обычного пользователя. Он вызовет `sudo`, если потребуется установить системные пакеты или обратиться к Docker. Для установки нужен Docker с Compose v2 и Buildx. [Инструкция для Kali](https://www.kali.org/docs/containers/installing-docker-on-kali/) · [Debian](https://docs.docker.com/engine/install/debian/) · [Ubuntu](https://docs.docker.com/engine/install/ubuntu/)

**Windows (PowerShell)**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Установщик использует уже настроенный Docker или устанавливает Docker Desktop через WinGet. При первом запуске может потребоваться завершить настройку Docker Desktop или перезагрузить Windows для WSL.

Откройте [SurfaceMap](http://localhost:8080), когда установщик выведет адрес. Терминал и **Tool Manager** показывают очередь, скачивание, сборку и ошибки. Панель доступна во время подготовки сканеров. [Документация API](http://localhost:8080/api/docs)

<a id="audit"></a>

## Первый аудит

1. Создайте проект. В **Authorized scope** добавьте разрешённые домены, IP-адреса или диапазоны CIDR. Исключения имеют приоритет.
2. Откройте **Audit** и проверьте план. Для небольшой проверки выберите **Baseline**. **Full surface audit** включает все доступные этапы.
3. Следите за **Audit activity** и журналами сканеров. Проверьте пропущенные и частично завершённые этапы.
4. Откройте **Map this audit**, чтобы увидеть связи. Используйте **Edit discovered map** для редактирования карты или экспортируйте карту и отчёт.

Можно познакомиться с интерфейсом без запуска сканера. В **Import Center** выберите **Nmap XML** и загрузите [пример](examples/sample-nmap.xml).

Поддерживаются **Nmap**, **Subfinder**, **DNSx**, **httpx**, **OWASP Amass**, **Nuclei**, **Katana** и **FFUF**. В **Scan Jobs** можно менять параметры, запускать свои команды и сохранять пресеты. Отчёты доступны в JSON, CSV, HTML и PDF.

<a id="commands"></a>

## Команды

После установки откройте новый терминал. Команды работают из любой папки.

| Команда | Действие |
| --- | --- |
| `surfacemap start` | Запустить приложение |
| `surfacemap stop` | Остановить стек и освободить порт с сохранением проектов |
| `surfacemap restart` | Перезапустить стек |
| `surfacemap status` / `surfacemap tools` | Проверить сервисы или версии сканеров |
| `surfacemap logs worker` | Смотреть журнал сканеров. Для API укажите `api`, для всех сервисов опустите имя. |
| `surfacemap doctor` | Проверить Docker и конфигурацию |
| `surfacemap update` | Обновить образы базы и Redis и пересобрать приложение из текущих исходников |
| `surfacemap help` / `surfacemap version` | Показать справку или версию |

Кнопка **Full stop** показывает команду останова. На Windows можно также дважды нажать `stop.cmd`. Чтобы изменить порт, задайте `API_PORT` в `.env` и выполните `surfacemap restart`.

<a id="troubleshooting"></a>

## Решение проблем

**Linux не находит команду.** В папке проекта выполните:

```bash
bash ./install.sh --register-cli
export PATH="$HOME/.local/bin:$PATH"
hash -r
surfacemap help
```

Из папки проекта можно вызвать `bash ./surfacemap status`, даже если при распаковке пропало право на исполнение. На файловой системе, которая разрешает прямой запуск, его можно вернуть командой `chmod u+x ./surfacemap`.

**Windows не находит команду.** Откройте новое окно PowerShell. Для восстановления регистрации выполните из папки проекта `powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -RegisterCli`.

**Сканер не готов или выдал ошибку.** Откройте **Tool Manager → Installation history** и разверните нужную операцию. При первой установке может отображаться более старая версия Nmap, пока собирается закреплённая. После устранения причины используйте **Tool Center → Install or update all adapters**. [Больше сценариев диагностики](docs/troubleshooting.md)

<a id="uninstall"></a>

## Полное удаление

Оставьте Docker запущенным. На Windows дважды нажмите `uninstall.cmd`, на Linux выполните `bash ./uninstall.sh` из папки проекта. Введите `DELETE` для подтверждения. Скрипт удалит проекты, результаты сканов и регистрацию команды. Затем можно удалить папку проекта и очистить данные сайта SurfaceMap в браузере.
